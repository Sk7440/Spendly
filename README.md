 Spendly — Modern Personal Finance Dashboard

Spendly is a modern, responsive personal finance dashboard designed to help users track income, manage expenses, and maintain financial clarity through clean analytics and real-time updates.

Features
Real-Time Financial Overview: Live balance, income, and expense calculations.
Interactive UI & Animations: Smooth animations powered by GSAP, Anime.js, and custom interactive components.
Transaction Management: Easily add, edit, and delete income or expense entries.
Filtering Options: Filter transactions by type (Income vs. Expense) for quick insights.
Local Storage Persistence: Data remains saved locally in your browser across page refreshes.
Responsive Dark Theme: Built with Tailwind CSS and CSS custom variables for a modern fintech aesthetic.

Tech Stack

- HTML5 & CSS3 (Custom Properties, Flexbox, CSS Grid)
- Tailwind CSS (Utility-first styling via CDN)
- JavaScript (ES6+) (DOM Manipulation, LocalStorage API)
- Animation Libraries:
  - [GSAP](https://greensock.com/gsap/) (ScrollTrigger, TextPlugin, SplitText, ScrollToPlugin)
  - [Anime.js](https://animejs.com/)


Prerequisites

All dependencies (Tailwind CSS, GSAP, Anime.js) are loaded via CDN, so no extra package installation is required to run the project.
